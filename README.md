# Typewriter-Ghost
A website that simulates a vintage typewriter slowly typing out a randomly chosen line from a public-domain novel, then erasing it one letter at a time as if haunted. (originally made for macondo but submitted here-)

# Features
- just animations nothing for you to do-
- sometimes haunted

## Getting Started

### Dependencies

You'll need:

- Node.js
- npm
- A modern web browser

### Installing

1. Clone the repository:

```bash
git clone https://github.com/keerts08/typewriter-ghost
```

2. Navigate into the project directory:

```bash
cd typewriter-ghost
```

3. Install the dependencies:

```bash
npm install
```

### Executing

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal (usually `http://localhost:3000`) to access typewriter-ghost.

## Help

If the project doesn't start, make sure Node.js is installed and that you've run `npm install` inside the project directory. If a port is already in use, stop the other process using it or let the development server choose another port.
